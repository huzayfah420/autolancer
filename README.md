# Autolancer

An autonomous end-to-end freelancer with you as the boss. From discovery to delivery.

## Project structure

Project code: **p07**. All project materials are organized under [`p07-autolancer/`](p07-autolancer/).

| Folder | Contents |
| --- | --- |
| `Management/Plan` | Project plan |
| `Requirements` | Requirements list and specifications |
| `Architecture` | High-level and low-level system architecture |
| `Prototype` | Prototype code and README |
| `Testing` | Testing strategy and test cases |
| `Development/Sprint-1` to `Sprint-4` | Sprint code, README, video, deployment, and configurations |
| `Final Deliverables/Code` | Complete system code |
| `Final Deliverables/Report` | Final project report |
| `Final Deliverables/Presentation` | Poster, presentation, and video demonstration |
| `Security` | Security reports |
| `Reviews` | Reviews by instructors |
